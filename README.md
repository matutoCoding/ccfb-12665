# 山地风电场微观选址与尾流仿真系统

浏览器端(TypeScript + WebGL2, 无框架)的山地风电场微观选址与尾流仿真工具。

## 运行

```bash
npm install
npm run dev      # 开发, 默认 http://127.0.0.1:5178
npm run build    # 生产构建(含类型检查) -> dist/
```

打开后自带「云岭山区 20 机位」示例项目: 5km×5km 山区地形、两座测风塔一年逐时数据、
20 个山脊机位、8 户居民点, 打开即可查看尾流与发电量, 无需自备数据。

## 页面

| 页面 | 功能 |
|---|---|
| 项目 | 项目列表/新建副本/删除; 项目存于浏览器 localStorage, 地形与测风数据按种子确定性重建 |
| 地形建模 | D8 汇流自动提取山脊线(排机位参考)与汇水冲沟(禁排区), 排水走向三维箭头, 冲沟缓冲距离可调 |
| 机位布置 | 机位表(坐标/发电量/尾流损失/IEC 湍流提示)、地图加点、吊装平台逐台土方与全场挖填平衡、集电线路分组与报警、逐户噪声核算、机位自动优化 |
| 风资源 | 测风塔分扇区威布尔/切变/湍流、风玫瑰、四项折减逐项设置、轮毂高度切换全场重算、50m 网格资源图叠加、Jensen 模型解析解校验 |
| 报告 | 全场指标、机位坐标与单机年发电量、尾流损失占比、容量系数、噪声结论, 导出 Markdown/CSV |

## 计算模型(与 WAsP 对照的要点)

- **风资源**: 逐时数据分 12 扇区做威布尔 MLE 拟合(A/k)、分扇区幂律风切变 α;
  任意轮毂高度按 v(z)=v_ref·(z/z_ref)^α 垂直外推; 多塔之间逆距离加权。
- **空气密度**: ISA 标准大气 ρ(h)=ρ₀(1−2.2558e−5·h)^4.2577, 额定功率以下 P∝ρ 修正功率曲线。
- **尾流**: Jensen/PARK 模型, δ=(1−√(1−Ct))·(r₀/(r₀+kx))², k=1/(2·ln(z_hub/z₀));
  部分遮挡按尾流截面与下游叶轮重叠面积加权; 多机叠加取平方和 √Σδᵢ²;
  12 扇区轮流扫描, 各扇区 Ct 取该扇区平均风速对应值。
  风资源页内置解析解校验表(3D/5D/8D/10D 中心线亏损), 模型输出与解析解完全一致。
- **年发电量**: 每机位每扇区用威布尔分箱积分 E=8760·Σf_s·∫P(v)·f_wb(v;A_s(1−δ),k_s)dv,
  尾流亏损等效为威布尔尺度参数缩减(与 PARK 标准处理一致); 可利用率/限电/叶片污染/场用电逐项连乘折减。
- **土方**: 平台尺寸与边坡坡比由机型确定, 走向按挖填总量最小自动选取(15°步长),
  5m 采样网格逐台核算挖方/填方, 全场汇总挖填平衡; 平台与边坡直接开挖到三维地形上。
- **噪声**: 机型倍频程声功率级 → ISO 9613 距离发散+大气吸收+地面吸收+地形遮挡(Maekawa 屏障衰减),
  A 计权叠加逐户核算昼夜等效声级, 超标户按主导声源发散衰减估算需退让距离。
- **集电线路**: 按升压站方位贪心分组, 单回路机组数超限报警, 电缆长度沿地形剖面三维累计(含 3% 弧垂)。
- **自动优化**: 候选点池(满足区域/冲沟缓冲/最小间距约束)+ 贪心初始解 + 逐机位交换局部搜索,
  目标为含尾流与折减的全场净年发电量最大; 迭代过程实时显示当前最优解, 可一键落成正式布置。

## 性能

地形 200×200 网格(8 万三角形)一次建缓冲; 机组/房屋全部实例化渲染(单次 draw call);
50 台机组全开实测 60 FPS, 布局变化全量重算(风资源表+尾流+土方+电气+噪声)约 90ms。

## 已知简化(后续可扩展)

- 自由流场未做 WAsP 式的地形加速效应(orographic speedup)CFD 修正, 空间变化来自多塔 IDW 插值;
- 粗糙度分区目前用于展示, 尚未耦合进切变/尾流衰减的局地化;
- 优化目标暂未计入土方造价与集电线路造价的综合经济性。
